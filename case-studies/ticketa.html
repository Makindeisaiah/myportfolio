01 / PROJECT OVERVIEW

About the project

Ticketa is an event ticketing and management platform designed to connect event organizers, attendees and check-in staff within one ecosystem.

The platform provides event discovery, ticket purchasing, event management, sales monitoring and attendee validation. It was developed with the goal of simplifying event operations and improving the ticketing experience.

MY ROLE

Solo Designer & Developer

PROJECT DURATION

6–12 Months

PLATFORMS

Web & Mobile App Design

STATUS

Web Platform Built & Tested Locally

02 / THE PROBLEM

One event experience. Multiple disconnected needs.

The event industry needs one integrated platform connecting organizers, attendees and check-in staff.

Managing ticket sales, attendee information, event operations and entry validation across disconnected processes can make event management more complicated.

03 / THE SOLUTION

One connected ecosystem.

01

Attendee Experience

Discover events, purchase tickets and access generated digital tickets.

02

Organizer Dashboard

Manage events, monitor ticket sales, review analytics and manage withdrawal requests.

03

Staff Check-in

Validate attendee tickets through QR scanning and manual verification.

04 / KEY FEATURES

Designed to simplify event operations.

  • Event discovery and ticket purchasing.
  • Paystack payment integration.
  • Automatic QR-code ticket generation after successful payment.
  • QR-code scanning and manual ticket validation.
  • Organizer event and ticket inventory management.
  • Sales analytics and revenue monitoring.
  • Withdrawal request management.
  • Dedicated staff check-in experience.

05 / DESIGN & DEVELOPMENT

From product design to implementation.

I handled the product design and development independently, working across the attendee website, organizer dashboard and staff check-in experience.

I also designed the attendee mobile application in Figma. The mobile application has not yet been developed.

07 / REFLECTION

What I learned.

The biggest challenge

Building interconnected experiences for organizers, attendees and check-in staff was the biggest challenge. Each user group needed different capabilities while remaining part of the same platform.

Key learning

Ticketa strengthened my understanding of end-to-end product development, from Figma design to functional full-stack implementation.
